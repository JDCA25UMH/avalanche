<h1>Avalanche</h1>

Juego con seis líneas verticales en la parte inferior de la pantalla, que se desplazan
horizontalmente, para atrapar unos bloques que descienden hasta un limite horizontal.
Tiene una línea vertical como sprite, y 3 tipos de bloque de distintos colores, 
ordenados por filas.
 
<img width="570" height="385" alt="Captura de pantalla 2026-11-11 094525" src="https://github.com/user-attachments/assets/877f0caa-bb2d-41cd-b853-84e1da2435c7" />

Se obtiene puntaje favorable al atrapar los bloques con las líneas verticales, y si llegan al limite horizontalse califica como perdida. 

Los bloques descienden acorde a un tiempo determinado, en el que se le indica al programa,
el hecho de que puede realizar una acción.
